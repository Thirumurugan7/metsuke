Two ways to run it. They are not the same thing and the difference matters.

↳

Subagent

  • Runs inside the thread you are in now
  • Gets the plan you wrote here, hands back a summary
  • Its file reads and searches never enter your context
  • Best for wide, throwaway work: find every X, check every Y
It does not share context back. You see the report, not the work. If you need the detail later, it is gone.
◆

Separate instance

  • Its own claude process and its own conversation
  • Its own git worktree and branch, so it cannot touch your files
  • Keeps running when you close the thread, and you can come back
  • Best for work that ends in a branch you review and merge
It starts cold. It reads CLAUDE.md, not this conversation, so it pays the onboarding cost every time you open one.
