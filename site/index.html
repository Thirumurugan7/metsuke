Watch Claude work

Open Claude is a code editor built around Claude Code. The file tree, the git diffs and the terminals move as the agent edits, and it drives a real browser to check that what it wrote still runs.

Available for macOS, Windows, and Linux

  • Visible

    Every file the agent touches shows up in the tree and the diff view while it is still typing. Nothing happens in a window you cannot see.

  • Direct

    Click a button in the preview, write one line about what is wrong, and Claude receives it with the exact CSS selector attached.

  • Tested

    Claude fills your forms, walks each screen, and reports the console errors and failed requests it hit on the way.

The agent and the browser share your screen

Claude gets browser tools the moment you open a folder. No extension to install, no config to write, no approval prompt on every click.

Preview

A browser the agent can actually use

The preview pane runs your dev server. Claude navigates it, clicks, types, and takes screenshots through the DevTools Protocol, so the events carry isTrusted and hit the same handlers a person would. It reads the console and the network log from the same page you are looking at.

The pane runs in an isolated session with an empty cookie jar. It holds none of your logins and cannot reach the editor or your files. That is what makes it safe to hand over without a permission prompt on every action.

Select mode

Point at it, then say what is wrong

Hit Select and click anything on the page. The inspector crosshair highlights as you hover, because it is Chromium's own picker rather than an overlay drawn on top.

Write one line about what should change. Claude gets your note with the selector already attached, so it never has to guess which button you meant.

UI audit

It tests the whole app, not the happy path

Start an audit and Claude builds a checklist of every screen it can reach, then works through it. It fills each form with real values and submits, retries with a bad email and an empty required field to see whether the app actually refuses, clicks the controls that do not submit, and checks the console after every step.

You get the list of screens it reached, a pass or fail per flow, and the console and network evidence behind each failure. It also says which parts it could not get to.

The rest of the editor

The things you would leave for if they were missing.

Real git

Status, staged and unstaged diffs, branches, push, pull, history. It runs the git binary, so your hooks, credential helpers and SSH config behave the way they do in your terminal.

Terminals that survive

As many Claude sessions and shells as you want, in tabs. Reload the window and it reattaches to the running processes and replays the scrollback.

Alerts that reach you

When Claude wants permission, a card floats above every app on whichever screen your cursor is on. Or your notification centre, a sound, or Telegram.

Ports, found for you

Dev servers you start appear on their own, flagged and sorted first. Databases and system daemons are filtered out so you never preview Postgres by mistake.

Monaco editing

The editor from VS Code, with per tab undo history. Files the agent rewrites under you refresh in place and keep your cursor where it was.

Quick open

⌘P and fuzzy matching that prefers filenames over directories. Search across the project jumps straight to the matching line.

You need Claude Code on your PATH. The editor runs the real claude CLI in its terminal. Everything else works without it.

Builds are not signed yet. On macOS, right click the app and choose Open the first time, or run xattr -dr com.apple.quarantine "/Applications/Open Claude.app". Windows SmartScreen warns once. On Linux, chmod +x the AppImage.
